## `SELECT` examples

<Tabs
    defaultValue="get_resource_policy"
    values={[
        { label: 'get_resource_policy', value: 'get_resource_policy' }
    ]}
>
<TabItem value="get_resource_policy">

Retrieves the resource policy for the specified CloudFront resource that you own and have shared.

```sql
SELECT
policy_document,
resource_arn
FROM aws.cloudfront.resource_policies
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
</Tabs>


## `REPLACE` examples

<Tabs
    defaultValue="put_resource_policy"
    values={[
        { label: 'put_resource_policy', value: 'put_resource_policy' }
    ]}
>
<TabItem value="put_resource_policy">

Creates a resource control policy for a given CloudFront resource.

```sql
REPLACE aws.cloudfront.resource_policies
SET 
ResourceArn = '{{ ResourceArn }}',
PolicyDocument = '{{ PolicyDocument }}'
WHERE 
region = '{{ region }}' --required
AND ResourceArn = '{{ ResourceArn }}' --required
AND PolicyDocument = '{{ PolicyDocument }}' --required
RETURNING
resource_arn;
```
</TabItem>
</Tabs>
