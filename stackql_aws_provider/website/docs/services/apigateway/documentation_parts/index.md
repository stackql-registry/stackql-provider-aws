<TabItem value="get_documentation_part">

Gets a documentation part.

```sql
SELECT
id,
location,
properties_
FROM aws.apigateway.documentation_parts
WHERE restapi_id = '{{ restapi_id }}' -- required
AND part_id = '{{ part_id }}' -- required
AND region = '{{ region }}' -- required
;
```
</TabItem>
<TabItem value="get_documentation_parts">

Gets documentation parts.

```sql
SELECT
id,
location,
properties_
FROM aws.apigateway.documentation_parts
WHERE restapi_id = '{{ restapi_id }}' -- required
AND region = '{{ region }}' -- required
AND type = '{{ type }}'
AND name = '{{ name }}'
AND path = '{{ path }}'
AND position = '{{ position }}'
AND limit = '{{ limit }}'
AND locationStatus = '{{ locationStatus }}'
;
```
