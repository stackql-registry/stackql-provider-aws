<Tabs
    defaultValue="get_work_group"

<TabItem value="get_work_group">

Returns information about the workgroup with the specified name.

```sql
SELECT
configuration,
creation_time,
description,
identity_center_application_arn,
name,
state
FROM aws.athena.work_groups
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
<TabItem value="list_work_groups">

Lists available workgroups for the account.

```sql
SELECT
next_token,
work_groups
FROM aws.athena.work_groups
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
</Tabs>

<TabItem value="update_work_group">

Updates the workgroup with the specified name. The workgroup's name cannot be changed. Only ConfigurationUpdates can be specified.

```sql
UPDATE aws.athena.work_groups
SET 
WorkGroup = '{{ WorkGroup }}',
Description = '{{ Description }}',
ConfigurationUpdates = '{{ ConfigurationUpdates }}',
State = '{{ State }}'
WHERE 
region = '{{ region }}' --required
AND WorkGroup = '{{ WorkGroup }}' --required;
```
