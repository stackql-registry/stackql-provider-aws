<TabItem value="get_notebook_metadata">

Retrieves notebook metadata for the specified notebook ID.

```sql
SELECT
creation_time,
last_modified_time,
name,
notebook_id,
type,
work_group
FROM aws.athena.notebook_metadatas
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
<TabItem value="list_notebook_metadata">

Displays the notebook files for the specified workgroup in paginated format.

```sql
SELECT
next_token,
notebook_metadata_list
FROM aws.athena.notebook_metadatas
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
</Tabs>

<TabItem value="update_notebook_metadata">

Updates the metadata for a notebook.

```sql
UPDATE aws.athena.notebook_metadatas
SET 
NotebookId = '{{ NotebookId }}',
ClientRequestToken = '{{ ClientRequestToken }}',
Name = '{{ Name }}'
WHERE 
region = '{{ region }}' --required
AND NotebookId = '{{ NotebookId }}' --required
AND Name = '{{ Name }}' --required;
```
</TabItem>
