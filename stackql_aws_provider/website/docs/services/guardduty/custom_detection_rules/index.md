<TabItem value="get_custom_detection_rule">

Returns details for a custom detection rule in GuardDuty, including its detection logic.

```sql
SELECT
arn,
created_at,
data_source,
definition,
description,
language,
name,
rule_id,
schema,
service,
severity,
tactic,
technique,
updated_at
FROM aws.guardduty.custom_detection_rules
WHERE rule_id = '{{ rule_id }}' -- required
AND region = '{{ region }}' -- required
;
```
</TabItem>
<TabItem value="list_custom_detection_rules">

Returns all available custom detection rules in GuardDuty. You can filter the results by data source, severity, tactic, technique, and service.

```sql
SELECT
arn,
created_at,
data_source,
description,
language,
name,
rule_id,
schema,
service,
severity,
tactic,
technique,
updated_at
FROM aws.guardduty.custom_detection_rules
WHERE region = '{{ region }}' -- required
;
```
</TabItem>
